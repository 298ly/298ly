## 研究与投稿经历

### 大模型提示词的因子交互与实验设计

**第一作者，投稿 AAAI 2027。现有记录显示已通过第一阶段、进入第二阶段评审；尚未录用或发表。**

研究关注一个问题：提示词的不同组成部分如何共同影响模型表现，某个提示方式的效果是否会随其他因素、任务和模型发生变化？

- 将提示词拆解为可控制的实验因素，通过多因素实验考察主效应与交互效应。
- 使用广义线性模型和似然比检验分析结果，关注统计显著性、效果大小和跨任务差异。
- 探索正交设计在有限评测预算下的应用，并与其他选优方法进行同预算比较；不把尚未充分支持的优势写成结论。
- 构建评测流程，支持分片运行、断点续跑、失败重试、解析器版本管理和结果完整性检查。
- 区分任务正确率、指令遵循和调用失败，保留从模型原始输出到统计分析的追溯关系。

此处仅介绍研究方向与投稿经历，不提供论文代码、实验数据或评审材料。

### [Student Career Copilot](https://github.com/298ly/student-career-copilot)

面向大学生与应届生的求职决策 Agent Skill，将岗位分析、事实证据、简历派生版本和面试反馈组织成可追溯的工作流。

- **证据管理：**区分已确认事实、自述、推测和未知信息，要求重要结论绑定来源。
- **任务路由：**根据岗位分析、简历修改、面试准备和结果复盘，加载对应参考规则。
- **决策约束：**岗位建议限定为五类动作，并解释依据，避免没有依据的精确匹配分数。
- **状态管理：**保留原始输入和版本记录，使后续复盘对应当时实际投递的材料。
- **辅助脚本：**提供工作区初始化和结构校验入口，支持持续使用。

项目由我在实际求职中持续使用，并根据岗位分析、面试准备和学习反馈迭代。已形成数据分析与信贷风控学习库、个人项目问答和公司专项材料；部分 SQL 学习内容配套样例验证程序与验证记录。

最新迭代增加“通用方向知识库—个人项目答案—公司专项”的三层组织，以及从问题、定义、公式、例子到边界和追问的零基础讲解要求。Python 脚本负责工作区初始化和结构校验。项目使用 AI 辅助开发；实际使用案例、脚本结构检查和岗位决策效果评测分别记录，不将自用经验推断为录用率提升。
